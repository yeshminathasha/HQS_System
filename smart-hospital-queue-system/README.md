# Smart Hospital Queue System

This project scaffold contains a starter backend and frontend structure for a smart hospital queue management system.

## Structure
- Backend: Express-style Node.js service with queue, patient, and appointment modules
- Frontend: React + Vite UI with dashboard and queue-related views
- Docs: project documentation placeholders

## Getting Started
1. Open the backend folder and install dependencies.
2. Open the frontend folder and install dependencies.
3. Start the backend and frontend servers.
